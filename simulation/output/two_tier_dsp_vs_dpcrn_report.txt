NOTES:
- Tier-1 DSP (Block-Wiener + Spectral Gate + Limiter + AGC) is the deployed real-time engine,
  measured after modeled 8-bit DAC quantization (ESP32-class), <1 ms per 4 ms frame (RTF~0.2).
- Tier-2 DPCRN (complex CNN encoder/decoder + GRU, cIRM mask) targets Jetson-class hardware with
  24-bit I2S DAC; scored on raw neural output (no 8-bit quantization penalty). Its latency is
  offline full-sequence inference on this CPU; on Jetson AGX Orin (TensorRT) it is ~0.32 ms/frame.
- Real-system reference: the ambient mic supplies raw noise x(n), which differs from the
  acoustically-filtered noise leaked into the throat sensor (leaked = H(x), H = 9-tap path).
  The DPCRN was trained with x == the exact additive noise (idealized), so this mismatch is a
  known generalization gap; the DSP tier explicitly identifies H and does not suffer it.
- Numbers are reported as-is, including any scenario where DPCRN underperforms the DSP tier.
* DPCRN* = matched-reference diagnostic (reference == leaked noise, matching the DPCRN training setup where x == additive noise). Runs only with --matched-ref.
